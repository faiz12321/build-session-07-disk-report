How to find what is using your disk space

Short answer

To find what fills a drive, add up file sizes folder by folder and look at the biggest ones first. This lesson builds a small Python tool that only reads, never changes or deletes anything, and lists what it could not read.

Follow along and build it step by step. You add each file yourself, run each command, and see the real recorded result.

Common mistakes

  1. Deleting before looking. First find out what is big. Often a few folders hold most of the space.
  2. Counting only the top level. A folder that looks empty can hold gigabytes in sub-folders. Add everything inside.
  3. Following shortcuts into loops. A shortcut can point back into the folder you are scanning. The tool skips shortcuts and links, so it cannot go round in a loop or count a file again through a shortcut. Real hard links (one file with two names) are still counted once per name.
  4. Treating "could not read" as zero. A folder the tool cannot open is not empty. The report lists what it could not read so you do not trust a total that is too low.
  5. Confusing file size with space used. A drive sets space aside in blocks, so the real space used can be a little larger than the sum of file sizes.

Frequently asked questions

How do I see what is using my disk space?

Add up the size of every file inside each folder and sort the folders from biggest to smallest. This lesson builds a small Python tool that does that and lists the biggest files too.

Will this delete anything?

No. The tool only reads names and sizes. It never opens a file to change it and has no delete step. The tests check that no name, size or modified time in the folder changes while it runs. They do not compare file contents.

Why is the total different from what Windows shows?

The tool adds up file sizes. Windows can show space used on disk, which is a little larger, and cloud folders such as OneDrive can list files that are not stored on your PC. The tool skips shortcuts and links, so it does not count a file again through them. Real hard links (one file with two names) are counted once per name.

What if a folder cannot be opened?

The tool carries on and tells you which folders it could not read. Treat the total as too low if the list is not empty.

Is it safe to run on my whole drive?

It only reads, but a whole drive can take a long time and many folders cannot be opened without administrator rights. Start with one folder such as Downloads.
